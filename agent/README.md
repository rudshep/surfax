# Host agent

The host agent will discover surfaces, manage pairing and sessions, and connect
surface input to the computer, VM, Proxmox host, or app.

Status: Not started.

Milestones: M1-M5 — discovery through controls and host bindings.

Linux is the first intended host platform. No implementation language or
runtime has been selected.

See [docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md) for the project context.
