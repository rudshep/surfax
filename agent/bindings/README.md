# Host bindings

Bindings project surface controls into host-side actions. Initial targets are
virtual HID and a JSON event stream; OSC, MIDI, ROS, and MQTT may follow.

Status: Not started.

Milestone: M5 — control descriptors, bindings, and safe disconnect behavior.

This directory is a design placeholder; no binding implementation or interface
has been selected.

See [docs/ARCHITECTURE.md](../../docs/ARCHITECTURE.md) for the project context.
