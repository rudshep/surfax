# RCSDP

This directory is reserved for the versioned Remote Control Surface Discovery
Protocol specification.

Status: Not started.

Milestone: M1-M2 — discovery, pairing, and persistent Surface identity.

The specification is intentionally empty while the project is in the design
phase. No wire format or compatibility guarantees have been decided.

See [docs/ARCHITECTURE.md](../ARCHITECTURE.md) for the project context.
