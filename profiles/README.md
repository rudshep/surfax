# Device profiles

Profiles describe a device's screen, input capabilities, and tested quirks.
They are intended to be one of the easiest ways to contribute.

Status: Not started.

Milestone: M2 — pairing and persistent Surface identity.

Start from [`TEMPLATE`](TEMPLATE). Its YAML-like format is **PROVISIONAL** and
not yet a protocol commitment.

See [docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md) for the project context.
