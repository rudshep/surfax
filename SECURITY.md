# Security policy

SURFAX targets old devices that may not support modern TLS. It is intended for
trusted local networks or VLANs only and must not be exposed to the internet.

To report a vulnerability privately, use GitHub's private vulnerability
reporting feature on this repository (the **Security** tab, then **Report a
vulnerability**). Please include steps to reproduce, affected versions or
devices, and any suggested mitigations. Do not open a public issue for an
unfixed vulnerability.
