# Android 4 surface

This target is a tiny, dependency-free native surface app for Android API 16
through 19.

Status: Not started.

Milestone: M6 — Android 4 surface experiments and implementation.

Experiments should cover discovery, pixel rendering, browser fallback, and
long-running behavior on actual devices.

See [docs/ARCHITECTURE.md](../../docs/ARCHITECTURE.md) for the project context.
