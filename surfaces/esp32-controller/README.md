# ESP32 controller

This directory is reserved for a reference DIY control surface using encoders,
buttons, a joystick, and LEDs.

Status: Not started.

Milestone: M5 — control descriptors, virtual HID, JSON events, and fail-safe
release on disconnect.

Hardware and firmware choices remain open; no implementation is included.

See [docs/ARCHITECTURE.md](../../docs/ARCHITECTURE.md) for the project context.
