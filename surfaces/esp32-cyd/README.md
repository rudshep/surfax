# ESP32 CYD surface

This is the player firmware target for the ESP32 Cheap Yellow Display, the
reference low-end display surface.

Status: Not started.

Milestones: M0-M4 — measure an existing VNC viewer, then discovery, pairing,
sessions, and touch.

The first experiment measures a stock viewer on real CYD hardware before
choosing a pixel transport.

See [docs/ARCHITECTURE.md](../../docs/ARCHITECTURE.md) for the project context.
